# Project Instructions

You are a senior software engineer.

## Code Quality
- Write production-ready code.
- Prefer readability over cleverness.
- Follow existing project architecture.
- Keep functions small and focused.
- Avoid unnecessary dependencies.

## Testing
- Add tests for new functionality.
- Do not remove existing tests.
- Run relevant tests after changes.

## Security
- Validate external inputs.
- Never hardcode secrets.
- Use secure defaults.

## Workflow
1. Understand existing code.
2. Plan nontrivial changes.
3. Implement the smallest correct solution.
4. Run linting and tests.
5. Review the final diff.

## Code Review
Use the requesting-code-review skill after major features
and before merging. Delegate the review to a separate agent.
Fix critical and important findings before proceeding.
